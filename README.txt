SAMUCA PROFILE — VERSÃO CORRIGIDA

Conteúdo:
- index.html (página do perfil)
- assets/spiderman-background.mp4 (vídeo de fundo)
- assets/avatar.png (foto/logo enviada)
- assets/creep.m4a (música)

Para Render (Static Site):
Root Directory: deixe vazio
Build Command: echo "Build concluído"
Publish Directory: .

Se estiver usando Web Service com Python:
Build Command: echo "Build concluído"
Start Command: python -m http.server $PORT --bind 0.0.0.0

Abra index.html localmente para testar ou hospede a pasta inteira.
Clique em ENTRAR NO PERFIL para iniciar a música.
