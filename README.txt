SAMUCA PROFILE

Site estatico para hospedagem.

Arquivos:
- index.html
- assets/avatar.png (foto enviada pelo usuario)
- assets/background.mp4 (video enviado pelo usuario)
- assets/creep.m4a (audio enviado pelo usuario)

Suba index.html e a pasta assets para a raiz do repositorio. Para Render Static Site, use Publish Directory: .
Para um servidor Python, Start Command: python -m http.server $PORT --bind 0.0.0.0

Nota: autoplay com audio pode ser bloqueado pelo navegador; use o player para iniciar. O video de fundo e muted e toca automaticamente.
A pagina exibe apenas um trecho curto de legenda de musica por limite de direitos autorais.
