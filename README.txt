SAMUCA PROFILE — SITE

Como abrir:
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Clique em "ENTRAR NO PERFIL" para iniciar a música.

O pacote inclui o vídeo de fundo e a música que foram enviados nesta conversa.
Para hospedar, envie a pasta inteira para um serviço de hospedagem estática (ex.: GitHub Pages).
